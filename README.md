# Handball Passion 🤾

Bienvenue sur **Handball Passion**, un petit site web consacré à la découverte du handball.

🌐 **Voir le site :** https://maelanjoli14.github.io/

## Présentation

Ce projet présente les principaux postes occupés par les joueurs sur un terrain de handball ainsi que différentes qualités et façons de jouer.

## Contenu du site

- **Les postes :** gardien de but, ailier gauche, ailier droit, arrière gauche, arrière droit, demi-centre et pivot.
- **Les styles de jeu :** joueur rapide, puissant, précis, organisateur, défensif et collectif.
- **Une conclusion :** l'importance de la complémentarité et du jeu en équipe.

## Technologies utilisées

- HTML5 pour structurer la page.
- CSS3 pour la mise en forme et l'adaptation aux écrans mobiles.
- Git et GitHub pour le suivi des versions et l'hébergement.
- GitHub Pages pour publier le site.

## Organisation du dépôt

- `index.html` : page principale du site (HTML et CSS intégrés).
- `README.md` : présentation du projet et de son contenu.

## Publication

Le site est publié avec GitHub Pages depuis la branche `main`, dossier racine (`/root`).
